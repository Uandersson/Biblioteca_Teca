# Sistema de Gerenciamento de Biblioteca

Projeto desenvolvido em Python com o objetivo de praticar Programacao Orientada a Objetos (POO), aplicando conceitos de organizacao, modularizacao e relacionamento entre classes.

## Objetivo

Desenvolver um sistema de gerenciamento de biblioteca capaz de controlar livros, usuarios, emprestimos e devolucoes.

## Funcionalidades

- [ ] Cadastro de livros.
- [ ] Cadastro de usuarios.
- [ ] Consulta de livros disponiveis.
- [ ] Realizacao de emprestimos.
- [ ] Devolucao de livros.
- [ ] Consulta de livros emprestados.
- [ ] Historico de emprestimos.

## Conceitos praticados

- Classes e objetos.
- Atributos e metodos.
- Construtores (`__init__`).
- Encapsulamento.
- Heranca.
- Polimorfismo.
- Relacionamento entre classes.
- Modularizacao.
- Importacao de modulos e pacotes.

## Estrutura do projeto

```text
biblioteca/
app/
    livro/

```

## Tecnologias

- Python 3
- Programacao Orientada a Objetos (POO)
